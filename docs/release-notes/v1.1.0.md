# AVMatrix VC12-4K driver 1.1.0

A rework of the upstream driver: correct frame delivery to several programs, DV timings, high refresh rates, suspend and resume, a safe unplug, cleaner audio, a DKMS installer with Secure Boot support, and an optional zero-copy mode. [CHANGELOG.md](../../CHANGELOG.md) lists the changes and [README.md](../../README.md) explains the install.

## Install

```sh
git clone --branch v1.1.0 https://github.com/bhoglo/AVMATRIX-VC12-4K-CAPTURE.git
cd AVMATRIX-VC12-4K-CAPTURE
./install.sh
```

Uninstall any older version of this driver first with the new `./uninstall.sh`. It also removes what the old `scripts/hws-*.sh` installers left.

## Tested hardware

- AVMatrix VC12-4K, PCI ID `8888:8581`, FPGA version 122.
- AMD Ryzen 9 9950X3D, x86-64. No other architecture was tested.
- Sources: Nintendo Switch 2, PlayStation 5, and the PC's own AMD Radeon RX 9070 (see the known issue).
- Other AVMatrix PCI IDs bind to the driver but are untested.

## Limitations

- YUYV 4:2:2 only, one HDMI input.
- Input up to 3840×2160 at 60 Hz and 1920×1080 at 240 Hz. The card scales a 4096×2160 source to 3840×2160.
- Audio 48 kHz, stereo, 16-bit only.
- No HDR or 10-bit video.
- HDCP-protected video arrives as black frames.
- Output sizes other than the input's are scaled on the CPU.

## Known issue

Changing the resolution of the PC's own GPU output while the card captures it, or shortly after the driver loads, made an AMD Radeon RX 9070 drop off the PCIe bus three times. Nothing found ties it to a driver defect. Set the resolution before you start capturing and leave it. Consoles and other PCs as sources are not affected as far as tested.
